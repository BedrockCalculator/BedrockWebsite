Frequently Asked Questions

Is this utility bannable?
The tool processes entirely client-side structural data that your game already loads. However, using automation tools may breach specific server rules. Always review your local realm guidelines.
How many bedrock blocks are needed to find a base?
Typically a clear 3x3 or 4x4 patch of uninterrupted bottom-layer bedrock is enough for the engine to match the pattern array and pinpoint coordinates.
Does this support versions other than Fabric?
No, the architecture relies directly on Fabric Language Kotlin asynchronous hooks for rendering without impacting your client's frame rates.
